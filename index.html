🚀 What is Tailwind CSS?
Tailwind CSS is a utility-first CSS framework that provides small, reusable utility classes for styling HTML elements directly.
Instead of creating custom CSS classes for every component, you combine utility classes to build your UI.


For example:
flex items-center justify-center p-4 bg-black text-white rounded-lg
These classes control layout, spacing, colors, typography, borders, responsiveness, and more.
